# Contribuições

Crie uma branch de trabalho a partir da main atual do repositório oficial. Faça alterações revisáveis e use a identidade Git da pessoa responsável. Confira o diff e execute a verificação do índice e os testes do [guia Windows](docs/EXECUCAO_LOCAL_WINDOWS.md).

Inclua apenas arquivos de distribuição revisados. Mantenha bases particulares, credenciais, evidências locais e fixtures geradas fora do Git. Documente proveniência, unidade, fuso e partição conforme o [guia dos modelos](docs/INTEGRACAO_MODELOS.md).

Envie a branch de trabalho e abra uma proposta de integração conforme a autorização do grupo. A produção usa a main revisada, conforme o [guia de deploy](docs/DEPLOY_STREAMLIT.md).
